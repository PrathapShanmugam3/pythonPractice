# pythonPractice – personal learning system

Each subject folder (`Angular/`, `Java/`, `React/`, …) contains a `<Subject>_Zero_to_Master.pdf` covering every topic from
beginner to master level, with code examples, interview questions and a project list.

`Angular/` additionally has the full structure: roadmap, one PDF per topic in `Notes/` (with Tamil real-world examples),
verified example programs in `Programs/` and an Excel progress tracker.

Rebuild with `python tools/build_subject.py angular` and `python tools/build_guides.py`. See `CLAUDE.md`.
