# AIML Learning - Zero to Master (Tamil + English / Tanglish)

* `pdfs/` - 15 PDFs (00 roadmap -> 14 glossary). Each topic has: English explanation, Tanglish explanation, example program, YouTube link.
* `AIML_Learning_Tracker.xlsx` - all topics in one sheet (filter + Status dropdown + notes), plus Weekly_Plan, YouTube_Channels, Courses, Books, Datasets, Tools.
* `tools/` - source used to generate them. Edit `tools/content/*.py` then run `pip install reportlab openpyxl && python3 tools/build.py`.

Order: 00 Roadmap -> 01 Maths -> 02 Python Core -> 03 Python Libraries -> 04 Data Prep -> 05 ML -> 06 DL -> 07 CV -> 08 NLP -> 09 LLM/GenAI -> 10 RL -> 11 MLOps -> 12 Advanced -> 13 Projects/Interview -> 14 Glossary.

Note: YouTube links are search links (always valid) and channel links; other links are official docs/course sites.
